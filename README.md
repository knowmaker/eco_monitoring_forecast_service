# Eco Monitoring Forecast Service

Отдельный сервис часового прогнозирования концентраций газов для тепловой карты.

## Модель

Сервис использует одну полуфизическую модель и один текущий артефакт CatBoost, обученный на данных всех газов и станций. Физическая часть переносит и рассеивает поле концентраций, а CatBoost прогнозирует остаточную поправку. Код газа передаётся CatBoost как категориальный признак. В признаки входят:

- часовая история газов и скользящие статистики;
- координаты и идентификатор станции;
- прогноз погоды Open-Meteo для исходного, транспортного и целевого часа;
- концентрации наветренных соседних станций, расстояния и оценка времени переноса;
- календарные признаки.

Обучение сразу атомарно заменяет текущий артефакт. Реестр кандидатов, ручная активация, отдельные модели по газам и история версий отсутствуют.

## Временной контракт

При запуске в `HH:10` используются данные с `data_cutoff = HH:00`, а прогноз строится для следующего полного календарного часа `(HH+1):00–(HH+2):00`. Один запуск рассчитывает все настроенные газы сразу для всех станций, имеющих достаточную локальную историю.

## Установка и БД

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
psql $env:DATABASE_URL -f forecast_schema.sql
```

Все таблицы сервиса создаются в общей схеме `public`.

## Подготовка, обучение и прогноз

```powershell
python -m app.features.hourly_gas --full
python -m app.features.weather_features --history
python -m app.training.train
python -m app.training.evaluate
python -m app.worker --once
```

`app.training.evaluate` выполняет несколько последовательных временных проверок и отдельные проверки с исключением каждой станции из обучающей выборки. Команда не заменяет текущую модель.

Для однократного заполнения пространственной сетки по уже сохранённым наблюдениям и прогнозам:

```powershell
python -m app.inference.concentration_grid --backfill
```

Постоянный почасовой worker:

```powershell
python -m app.worker --train-if-missing
```

Флаг также заменяет сохранённый артефакт старого формата после обновления сервиса.

После каждого почасового прогноза worker строит сетку концентраций с ячейкой 100 × 100 метров и буфером 1000 метров. Предыдущий прогноз корректируется новыми измерениями, затем поле переносится ветром, рассеивается, ослабляется и дополняется поправкой CatBoost. Близкие станции объединяются в общую область, а для одиночной удалённой станции строится отдельная область без искусственного соединения с другими станциями. Сетка хранится только за последние 7 дней.

Отрицательные концентрации для обучения, физического расчёта и тепловой карты ограничиваются нулём, а не переводятся в модуль: измерительный шум не должен создавать дополнительную массу газа. Исходные записи `public.gas_sensors` не изменяются.

API для интерфейса:

```text
GET /api/v1/gases/heatmap/timeline
GET /api/v1/gases/heatmap
```
